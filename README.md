# 🤖 Bot-Ai-Discord

บอท Discord ที่เป็น AI แชทบอท ใช้ **AI API ฟรี** (Google Gemini เป็นตัวหลัก สลับไป Groq หรือ OpenRouter ได้ผ่าน `.env`) รองรับภาษาไทย

## ✨ ฟีเจอร์

| ถามได้ 3 แบบ | `@ชื่อบอท คำถาม`, `/ask question:คำถาม` หรือพิมพ์ใน**ห้องคุยกับ AI** ได้เลยไม่ต้องใช้คำสั่ง |
| ห้องคุยกับ AI | `/aichannel เปิด` ในห้องไหน บอทจะตอบทุกข้อความในห้องนั้น (รวมเธรดในห้องนั้น) พร้อมการ์ดวิธีใช้ที่ปักหมุดให้ |

| สถานะบอท | หมุนเวียนทุก 30 วินาที เช่น "💬 พิมพ์คุยในห้อง AI ได้เลย", "✨ ตอบไปแล้ว 120 ครั้ง" |

| กันเกินโควต้า | cooldown ต่อผู้ใช้ (`USER_COOLDOWN_SECONDS`) ใช้ร่วมกันทั้ง mention และ `/ask` |
| ปลอดภัย | ความลับอยู่ใน `.env` เท่านั้น, คำตอบของ AI ไม่สามารถ ping `@everyone`/`@here`/role ได้ |

## 🧰 ทำไมเลือก Python + discord.py

- **อ่านง่าย ติดตั้งน้อย** — ใช้แค่ 2 แพ็กเกจ (`discord.py`, `python-dotenv`) ส่วน `aiohttp` ที่ใช้เรียก AI API ติดมากับ discord.py อยู่แล้ว
- **async ทั้งหมด** — discord.py สร้างบน asyncio โดยตรง การเรียก AI ใช้ `aiohttp` แบบ async จึงไม่บล็อกบอทระหว่างรอคำตอบ
- **ไม่ผูกกับ SDK ของเจ้าใดเจ้าหนึ่ง** — เรียก REST API ตรง ๆ ทำให้สลับ Gemini / Groq / OpenRouter ได้ด้วยการแก้ `.env` บรรทัดเดียว และไม่พังเมื่อ SDK เปลี่ยนเวอร์ชัน
- discord.js v14 ก็ทำได้เท่ากัน แต่ต้องติดตั้งแพ็กเกจและตั้งค่าไฟล์มากกว่า (เช่น สคริปต์ deploy คำสั่งแยก) จึงเลือก Python เพื่อให้มือใหม่เริ่มได้เร็วกว่า

# 📖 คู่มือติดตั้งทีละขั้นตอน

## ขั้นที่ 1: สร้างบอทใน Discord Developer Portal

1. เข้า <https://discord.com/developers/applications> แล้วล็อกอินด้วยบัญชี Discord
2. กด **New Application** → ตั้งชื่อบอท → ติ๊กยอมรับเงื่อนไข → **Create**
3. เมนูซ้ายเลือก **Bot**
4. กด **Reset Token** → **Yes, do it!** → กด **Copy** เก็บ token ไว้ (จะเห็นแค่ครั้งเดียว)
   > ⚠️ **token = รหัสผ่านของบอท** ห้ามแชร์ ห้ามโพสต์ ห้าม commit ขึ้น GitHub ถ้าหลุดให้กด Reset Token ทันที

## ขั้นที่ 2: เปิด Message Content Intent

ยังอยู่ที่หน้า **Bot** เลื่อนลงไปหัวข้อ **Privileged Gateway Intents**

1. เปิดสวิตช์ **MESSAGE CONTENT INTENT** ✅ (จำเป็น ไม่งั้นบอทอ่านข้อความตอน mention ไม่ได้)
2. กด **Save Changes**

> ถ้าลืมขั้นนี้ ตอนรันบอทจะขึ้น error ว่า `ยังไม่ได้เปิด Message Content Intent`

## ขั้นที่ 3: เชิญบอทเข้าเซิร์ฟเวอร์

1. เมนูซ้ายเลือก **OAuth2** → **URL Generator**
2. ช่อง **Scopes** ติ๊ก: `bot` และ `applications.commands`
3. ช่อง **Bot Permissions** ติ๊ก:
   - `View Channels`
   - `Send Messages`
   - `Send Messages in Threads`
   - `Read Message History`
   - `Embed Links` (การ์ดวิธีใช้)
   - `Add Reactions` (รีแอคชัน 👀 ⚠️)
   - `Pin Messages` หรือ `Manage Messages` (ปักหมุดการ์ดวิธีใช้ — ไม่ให้ก็ได้ บอทจะข้ามไป)
   - `Create Public Threads` (โหมดเธรด — ไม่ให้ก็ได้ บอทจะตอบในห้องปกติ)
   - `Attach Files` (แนบคำตอบยาวเป็นไฟล์ .txt — ไม่ให้ก็ได้ บอทจะแบ่งเป็นหลายข้อความแทน)
4. คัดลอกลิงก์ด้านล่างสุด (Generated URL) ไปเปิดในเบราว์เซอร์
5. เลือกเซิร์ฟเวอร์ที่ต้องการ (ต้องมีสิทธิ์ **Manage Server**) → **Authorize**

**(แนะนำ) หา Server ID เพื่อให้ slash command ขึ้นทันที:**
Discord → User Settings → Advanced → เปิด **Developer Mode** → คลิกขวาที่ไอคอนเซิร์ฟเวอร์ → **Copy Server ID** → ใส่ใน `GUILD_ID` ของ `.env`

## ขั้นที่ 4: ขอ API key ฟรี (ไม่ต้องผูกบัตรเครดิต)

เลือกอย่างน้อย 1 เจ้า (แนะนำ Gemini)

### 🔷 Google Gemini (ตัวหลัก)
1. เข้า <https://aistudio.google.com/apikey> ล็อกอินด้วยบัญชี Google
2. กด **Create API key** → คัดลอก key
3. ใส่ใน `.env`: `AI_PROVIDER=gemini`, `GEMINI_API_KEY=...`
4. ตรวจชื่อโมเดลล่าสุดที่ <https://ai.google.dev/gemini-api/docs/models> แล้วใส่ใน `GEMINI_MODEL` (เช่น `gemini-3.8-flash`)
   - ดูโควต้าฟรีของแต่ละโมเดลได้ที่ <https://ai.google.dev/gemini-api/docs/rate-limits>
   - หมายเหตุ: ข้อมูลที่ส่งผ่าน free tier อาจถูก Google นำไปใช้ปรับปรุงบริการ อย่าให้ผู้ใช้ส่งข้อมูลส่วนตัว/ความลับ

### 🔎 Tavily (ค้นเว็บ — ไม่บังคับแต่แนะนำ)
1. เข้า <https://app.tavily.com> → สมัคร/ล็อกอิน (ไม่ต้องผูกบัตร ฟรีเดือนละ 1,000 ครั้ง)
2. คัดลอก API key (ขึ้นต้นด้วย `tvly-`) ใส่ใน `.env`: `TAVILY_API_KEY=tvly-...`

> 💡 **แนะนำ:** ขอ key ของ Groq ไว้ด้วย แล้วตั้ง `BACKUP_PROVIDER=groq` — โควต้าฟรีรายวันของ Gemini ค่อนข้างน้อย ถ้าหมดหรือ Gemini ล่ม บอทจะสลับไปตอบด้วย Groq ให้เองอัตโนมัติ

### 🟧 Groq (เร็วมาก)
1. เข้า <https://console.groq.com/keys> → สมัคร/ล็อกอิน → **Create API Key**
2. ใส่ใน `.env`: `AI_PROVIDER=groq`, `GROQ_API_KEY=...`
3. เลือกโมเดลจาก <https://console.groq.com/docs/models> ใส่ใน `GROQ_MODEL`

### 🟪 OpenRouter (รวมหลายโมเดล)
1. เข้า <https://openrouter.ai/keys> → สมัคร/ล็อกอิน → **Create Key**
2. ใส่ใน `.env`: `AI_PROVIDER=openrouter`, `OPENROUTER_API_KEY=...`
3. เลือกโมเดลฟรีจาก <https://openrouter.ai/models?max_price=0> — **ต้องเป็นชื่อที่ลงท้าย `:free`** เท่านั้น ถึงจะไม่เสียเงิน
   - บัญชีที่ไม่ได้เติมเงิน จะมีโควต้าต่อวันของโมเดล `:free` ค่อนข้างจำกัด

> 💡 **ทำไมชื่อโมเดลอยู่ใน `.env`:** โมเดลฟรีถูกเพิ่ม/ถอดบ่อย ถ้าวันหนึ่งบอทตอบว่า "🧩 ไม่พบโมเดล AI" และ log ขึ้น HTTP 404 แปลว่าโมเดลถูกถอดแล้ว (ข้อความ error ใน log มักบอกชื่อโมเดลใหม่ที่แนะนำ) — แค่เปลี่ยนชื่อโมเดลใน `.env` แล้วรีสตาร์ท ไม่ต้องแก้โค้ด

## ขั้นที่ 5: รันบนเครื่อง

**ต้องมี Python 3.10 ขึ้นไป** (ดาวน์โหลด: <https://www.python.org/downloads/> — บน Windows ติ๊ก "Add Python to PATH" ตอนติดตั้ง)

```bash

git clone https://github.com/x2Swiftyouz/Bot-Ai-Discord.git
cd Bot-Ai-Discord

# 2) สร้าง virtual environment
python -m venv .venv

.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3) ติดตั้งแพ็กเกจ
pip install -r requirements.txt

# 4) สร้างไฟล์ตั้งค่าจากตัวอย่าง แล้วเปิดแก้ใส่ token / API key
# Windows:
```

### 💬 ตั้งห้องคุยกับ AI (ไม่ต้องพิมพ์ /ask)

ไปที่ห้องที่ต้องการ แล้วพิมพ์ `/aichannel` → เลือก **เปิด** จากนั้นพิมพ์อะไรในห้องนั้น บอทจะตอบทุกข้อความ

| คำสั่ง | ผล |
|---|---|
| `/aichannel เปิด` | ตั้งห้องนี้เป็นห้องคุยกับ AI |
| `/aichannel ปิด` | ยกเลิก กลับไปใช้ `/ask` หรือ mention |
| `/aichannel สถานะ` | ดูว่าห้องไหนในเซิร์ฟเวอร์เปิดอยู่บ้าง |

- ค่าเริ่มต้น เฉพาะคนที่มีสิทธิ์ **Manage Channels** ใช้คำสั่งนี้ได้ (แอดมินปรับได้ที่ Server Settings → Integrations → ชื่อบอท)
- การตั้งค่าถูกบันทึกในไฟล์ `data/ai_channels.json` จึงยังอยู่หลังรีสตาร์ท — ถ้าโฮสต์ของคุณลบไฟล์ทุกครั้งที่ deploy ให้ใส่ ID ห้องใน `AI_CHANNEL_IDS` ของ `.env` แทน
- ข้อความที่มีแต่สติกเกอร์/ไฟล์อื่นจะถูกข้าม ส่วนรูปอย่างเดียวบอทจะอธิบายรูปให้ และยังมี cooldown ต่อผู้ใช้เหมือนเดิม
- พิมพ์ `//` นำหน้าข้อความ เช่น `// เดี๋ยวมานะ` บอทจะไม่ตอบ

## ⚙️ ค่าตั้งค่าทั้งหมดใน `.env`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DISCORD_TOKEN` | — | token ของบอท (จำเป็น) |
| `GUILD_ID` | ว่าง | ID เซิร์ฟเวอร์ ให้ slash command ขึ้นทันที (ว่าง = global อาจรอนาน) |
| `AI_CHANNEL_IDS` | ว่าง | ID ห้องคุยกับ AI แบบตายตัว คั่นด้วยจุลภาค (หรือใช้ `/aichannel` แทน) |
| `DATA_DIR` | `data` | โฟลเดอร์เก็บข้อมูลที่บอทสร้าง เช่น ห้องที่เปิดด้วย `/aichannel` |
| `AI_PROVIDER` | `gemini` | `gemini` / `groq` / `openrouter` |
| `<PROVIDER>_API_KEY` | — | key ของเจ้าที่เลือก (จำเป็นเฉพาะเจ้าที่ใช้) |
| `<PROVIDER>_MODEL` | — | ชื่อโมเดลของเจ้าที่เลือก |
| `BACKUP_PROVIDER` | ว่าง (อัตโนมัติ) | ผู้ให้บริการสำรอง ใส่ได้หลายเจ้าคั่นด้วยจุลภาค เช่น `groq,openrouter` — เว้นว่างจะใช้ทุกเจ้าที่กรอก key + โมเดลไว้, `none` = ไม่ใช้ |
| `<PROVIDER>_VISION_MODEL` | ว่าง | โมเดลที่ใช้เมื่อคำถามมีรูป (เช่น โมเดลฟรีของ OpenRouter ที่รับรูปได้) |
| `LOG_CHANNEL_ID` | ว่าง | ห้อง log ของแอดมิน (หรือใช้ `/logchannel` แทน) |
| `<PROVIDER>_API_KEYS` | ว่าง | key เพิ่มเติม คั่นด้วยจุลภาค — key แรกเกินโควต้าจะสลับไปตัวถัดไปเอง (ควรเป็นคนละโปรเจกต์ ไม่งั้นใช้โควต้าก้อนเดียวกัน) |
| `<PROVIDER>_FALLBACK_MODELS` | ว่าง | โมเดลสำรอง คั่นด้วยจุลภาค เช่น `รุ่น-a,รุ่น-b` ใช้เมื่อโมเดลหลักล่ม/เกินโควต้า/ถูกถอด |
| `AI_MAX_RETRIES` | `2` | ลองใหม่กี่ครั้งเมื่อเซิร์ฟเวอร์ AI ล่มชั่วคราว (รอ 1, 2, 4 ... วินาที) ก่อนสลับไปโมเดลสำรอง |
| `SYSTEM_PROMPT` | ผู้ช่วยที่เป็นมิตร | บุคลิกของบอท |
| `MEMORY_SIZE` | `10` | จำนวนข้อความที่จำต่อช่อง (ผู้ใช้+บอท) |
| `USER_COOLDOWN_SECONDS` | `10` | ต้องรอกี่วินาทีก่อนถามครั้งถัดไป |
| `AI_TIMEOUT_SECONDS` | `60` | รอ AI ตอบนานสุดกี่วินาที |
| `AI_TEMPERATURE` | `0.7` | ความสร้างสรรค์ของคำตอบ |
| `TIMEZONE` | `Asia/Bangkok` | เขตเวลาที่บอกให้ AI รู้วันเวลาปัจจุบัน |
| `TAVILY_API_KEY` | ว่าง | key ค้นเว็บ Tavily (ใส่แล้วจะใช้แทนการค้นของ Gemini) |
| `WEB_SEARCH` | `true` | ให้ Gemini ค้นเว็บได้เอง เมื่อไม่มี Tavily (free tier มักไม่มีโควต้า) |
| `MEMORY_PERSIST` | `true` | จำบทสนทนาลงไฟล์ ไม่หายเมื่อรีสตาร์ท |
| `DAILY_LIMIT_PER_USER` | `30` | คำถามสูงสุดต่อคนต่อวัน (`0` = ไม่จำกัด) แอดมินไม่ถูกจำกัด |
| `SHOW_FOOTER` | `true` | แสดงบรรทัดเล็กใต้คำตอบ |
| `STREAMING` | `true` | แสดงคำตอบค่อย ๆ พิมพ์ออกมา |
| `MAX_IMAGES` | `4` | จำนวนรูปสูงสุดต่อข้อความ (`0` = ปิดการอ่านรูป) |
| `MAX_IMAGE_MB` | `5` | ขนาดรูปสูงสุดต่อรูป (MB) |
| `MAX_FILE_MB` | `10` | ขนาดไฟล์เอกสารสูงสุดต่อไฟล์ (MB) |
| `MAX_FILE_CHARS` | `40000` | ตัวอักษรสูงสุดจากไฟล์ที่ส่งให้ AI (`0` = ปิดการอ่านไฟล์) |
| `LONG_ANSWER_FILE_CHARS` | `4000` | คำตอบยาวเกินนี้แนบเป็นไฟล์ .txt (`0` = ปิด) |
| `THREAD_AUTO_TITLE` | `true` | ให้ AI ตั้งชื่อเธรดหลังตอบคำถามแรก (ใช้คำขอ AI เพิ่ม 1 ครั้งต่อเธรด) |

## 🩺 แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `DISCORD_TOKEN ไม่ถูกต้อง` | คัดลอก token ผิด หรือ token ถูกรีเซ็ต → Reset Token ใหม่ |
| `ยังไม่ได้เปิด Message Content Intent` | ทำขั้นที่ 2 |
| log ขึ้น `FALLBACK_MODELS มี API key ปนอยู่` | ใส่ key ไว้ผิดช่อง บอทย้ายไปใช้เป็น key สำรองให้แล้ว แต่ควรย้ายไปไว้ที่ `<PROVIDER>_API_KEYS` แทน |
| ถามข่าวแล้วไม่ค้นเว็บ | ใส่ `TAVILY_API_KEY` แล้วหรือยัง · คำถามต้องมีคำอย่าง "ข่าว / ราคา / ล่าสุด / ผลบอล" หรือพิมพ์ขึ้นต้นด้วย `ค้นหา` เพื่อบังคับค้น |
| ผู้ใช้บอกว่า "ถามครบโควต้าแล้ว" | เพิ่ม `DAILY_LIMIT_PER_USER` หรือใส่ `0` เพื่อไม่จำกัด · ดูการใช้งานได้ที่ `/stats` |
| ไม่เห็นเมนู `แปลภาษา (AI)` ตอนคลิกขวา | อยู่ในเมนูย่อย **Apps** · รีสตาร์ทบอทแล้วกด `Ctrl+R` รีโหลด Discord |
| Gemini หมดโควต้าแล้วส่งรูปไม่ได้ | ตั้ง `OPENROUTER_VISION_MODEL` เป็นโมเดลฟรีที่รับรูปได้ (ดูที่ openrouter.ai/models ตัวกรอง Input: image + ราคา 0) |
| ห้อง log ไม่มีข้อความ | ใช้ `/logchannel ทดสอบ` · บอทต้องมีสิทธิ์ Send Messages + Embed Links ในห้องนั้น |
| เปิดโหมดเธรดแล้วบอทยังตอบในห้อง | บอทไม่มีสิทธิ์ `Create Public Threads` ในห้องนั้น (ดู log: `เปิดเธรดไม่ได้`) |
| แนบ PDF แล้วบอทบอกว่าอ่านไม่ได้ | PDF แบบภาพสแกน (ไม่มีตัวหนังสือในไฟล์) อ่านได้เฉพาะตอนใช้ Gemini · PDF ที่มีรหัสผ่านอ่านไม่ได้ |
| คำสั่งขึ้นซ้ำ 2 อัน (เช่น `/reset` 2 ตัว) | มีคำสั่งค้างจากโปรแกรมอื่นหรือจากการตั้งค่าเก่า → รีสตาร์ทบอท บอทจะลบคำสั่งที่ไม่ใช่ของตัวเองให้เอง (log ขึ้น `ลบคำสั่งที่ค้าง`) แล้วกด `Ctrl+R` รีโหลด Discord |
| ไม่เห็น `/ask` | ใส่ `GUILD_ID` แล้วรีสตาร์ท, ตรวจว่าเชิญบอทด้วย scope `applications.commands`, ลองกด `Ctrl+R` รีโหลด Discord |
| ส่งรูปแล้วบอทตอบ "ระบบ AI มีปัญหา" (Groq/OpenRouter) | โมเดลที่เลือกอ่านรูปไม่ได้ → เลือกโมเดลที่รองรับ vision หรือใช้ Gemini |
| ไม่มีรีแอคชัน 👀 / การ์ดไม่ถูกปักหมุด | บอทไม่มีสิทธิ์ Add Reactions / Pin Messages ในห้องนั้น (ให้สิทธิ์ที่ role ของบอท) |
| กดปุ่มแล้วขึ้น "การโต้ตอบนี้ล้มเหลว" | บอทถูกรีสตาร์ทหลังส่งคำตอบนั้น ปุ่มเก่าจึงใช้ไม่ได้ — ถามใหม่ได้เลย |
| log ขึ้น `ใช้ค้นเว็บไม่ได้ จะตอบแบบไม่ค้นเว็บแทน` | โมเดลนั้นไม่รองรับการค้นเว็บ บอทจะตอบแบบไม่ค้นเว็บให้เองจนกว่าจะรีสตาร์ท ไม่ต้องทำอะไร |
| บอทตอบ "⏳ เกินโควต้าฟรี" (HTTP 429) | ดูใน log บรรทัด `HTTP 429` จะบอกว่าโควต้าตัวไหนหมด (ต่อนาที / ต่อวัน) — ถ้าโควต้าค้นเว็บหมด บอทจะพักการค้นเว็บ 30 นาทีแล้วตอบแบบไม่ค้นเว็บให้เอง ถ้าโควต้ารายวันหมดต้องรอรีเซ็ต (ประมาณเที่ยงคืนเวลาแปซิฟิก ≈ บ่าย 2–3 โมงเวลาไทย) หรือใส่โมเดลสำรอง |
| Gemini ล่มแล้วส่งรูปไม่ได้ ทั้งที่ตั้ง `BACKUP_PROVIDER` ไว้ | โมเดล Groq ที่เลือกอ่านรูปไม่ได้ → เปลี่ยน `GROQ_MODEL` เป็นโมเดลที่รองรับรูป (vision) หรือรอ Gemini กลับมา |
| reply ข้อความแล้วบอทไม่เห็นข้อความนั้น | บอทต้องมีสิทธิ์ `Read Message History` ในห้องนั้น |
| ไม่เห็นคำสั่ง `/aichannel` | ต้องมีสิทธิ์ Manage Channels และอัปเดตโค้ด + รีสตาร์ทบอทแล้ว |
| mention แล้วบอทเงียบ | บอทไม่มีสิทธิ์ View/Send ในช่องนั้น หรือยังไม่เปิด Message Content Intent |
| บอทตอบ "🔑 API key ไม่ถูกต้อง" | ตรวจ `*_API_KEY` ให้ตรงกับ `AI_PROVIDER` |
| บอทตอบ "🔥 เซิร์ฟเวอร์ AI มีคนใช้งานหนาแน่น" + log `HTTP 503` | ฝั่งผู้ให้บริการ AI คนใช้เยอะชั่วคราว ไม่ใช่ความผิดของบอท → รอสักพัก หรือใส่ `<PROVIDER>_FALLBACK_MODELS` เป็นโมเดลอื่น (เช่นรุ่นเล็กกว่า) ไว้สำรอง |
| บอทตอบ "⏳ เกินโควต้าฟรี" | โดน rate limit → รอสักพัก, เพิ่ม `USER_COOLDOWN_SECONDS`, หรือสลับไปเจ้าอื่น |
| บอทตอบ "🧩 ไม่พบโมเดล AI" + log `HTTP 404` | ชื่อโมเดลผิดหรือโมเดลถูกถอด → เปลี่ยน `*_MODEL` — ตอนเริ่มบอท log จะขึ้น `⚠️ ... ไม่มีโมเดล ... ตัวอย่างโมเดลที่ใช้ได้ตอนนี้: ...` ให้เลือกจากรายชื่อนั้น |
| Gemini เกินโควต้าแล้วไม่สลับไปตัวสำรอง | ตัวสำรองก็ใช้ไม่ได้ (เช่น โมเดล Groq ถูกถอด) → ดู log ตอนเริ่มบอท แล้วแก้ `GROQ_MODEL` |
| log ขึ้น `PyNaCl is not installed, voice will NOT be supported` | เป็นแค่คำเตือนเรื่องระบบเสียง บอทนี้ไม่ใช้เสียง ไม่ต้องสนใจ |

> หมายเหตุ: ความจำเก็บในหน่วยความจำ (RAM) — รีสตาร์ทบอทแล้วความจำจะหายหมด

### ตัวอย่าง: รันค้างบน Linux VPS ด้วย systemd

```ini
# /etc/systemd/system/discord-ai-bot.service
[Unit]
Description=Discord AI Bot
After=network-online.target

[Service]
WorkingDirectory=/home/ubuntu/Bot-Ai-Discord
ExecStart=/home/ubuntu/Bot-Ai-Discord/.venv/bin/python main.py
Restart=always
RestartSec=10
User=ubuntu

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now discord-ai-bot
journalctl -u discord-ai-bot -f   # ดู log
```

`Restart=always` จะรีสตาร์ทบอทให้อัตโนมัติถ้าเครื่องรีบูตหรือโปรแกรมหยุด
